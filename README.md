Ejercicios Java de Francisco Carrizo 53320

Proyecto Maven con ejercicios de práctica en Java 21, organizados por paquetes (`ej1`, `ej2`, `ej3`, `ej4`) dentro de `dev.francarri`.

## Contenido

- ej1 – ej3: ejercicios varios (manejo de archivos, colecciones, etc.).
- ej4: gestión de eventos universitarios con actividades (charlas, talleres y cursos), inscripciones de estudiantes, salas, excepciones propias e hilos.

## Requisitos

- JDK 21
- Maven 3.8+

## Uso
```

También podés ejecutar cada clase `App` directamente desde el IDE.
```
